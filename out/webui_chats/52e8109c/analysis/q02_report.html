Atlys — Some Charts

Five views across the live clickathon database (service 78f5870d…), each queried fresh on 2026-08-02. Funnels are computed by exact set-membership join on user_id/group_id, never windowFunnel (per known_issues.md → D1, which silently drops 52% of true conversions on this data).

1. Main visa-application funnel

Baseline event tables · H1 2026 window (2025-12-31→2026-07-01) · 1,000,000 users at top of funnel

Bar widths use a log scale (real magnitude spans 1,000,000→7,054) so every stage stays visible. End-to-end funnel_conversion = 7,054 / 154,413 = 4.57% (purchases ÷ applications started — the wiki's named default denominator, not ÷ card-clicks which gives an unrelated 0.71%). All counts are live re-derivations and match documented figures exactly.

2. Group/Family completion rate by group size

Spec 02 sample · 2026-06-08→2026-06-28 · 1,200 groups started (join on group_id, standalone from main funnel — D2: application_id 0% overlap)

Rate = groups reaching group_submitted ÷ groups in group_started, joined on group_id. Monotonic decline confirmed live: bigger groups convert worse, from 69.47% (2 travellers) to 31.11% (6 travellers).

3. Instant Forex add-on attach rate by destination

Spec 05 sample · 2026-06-08→2026-06-28 · 2,900 offers shown, 14 destinations shown here (join on user_id, standalone — D2 STOP)

Attach rate = forex_purchased ÷ forex_offer_shown per destination, joined on user_id. Best: US 24.58% (n=236 shown). Worst: AU 13.78% (n=196 shown) — a real ~11pp spread, matching metrics/forex_attach_rate.md.

4. Abandoned-checkout recovery rate by drop step

Spec 04 sample · 2026-06-08→2026-07-01 · 2,300 abandonments total (join on user_id, standalone — D2 STOP)

Recovery rate = reconverted ÷ abandonment_detected per drop_step. Flat 4.45%–4.80% for the first 3 funnel steps, notably worse (2.62%) for the earliest drop point, destination_card_clicked — matches metrics/recovery_rate.md.

5. Monthly funnel conversion trend (application → purchase)

Baseline tables · Jan–Jun 2026 (July excluded: only 9 rows, a partial first-week fragment)

Monthly uniqExactIf(purchase_completed IN application_started) ÷ uniqExact(application_started), set-membership not windowFunnel. A real portfolio-wide decline: 4.94% (Jan, n=21,580 applications) → 3.96% (Jun, n=30,370 applications), ~20% relative drop, even as application volume grew. Per known_issues.md → K4, this decline is not Schengen-specific (a prior hypothesis) — Schengen and non-Schengen destinations track within ±0.3pp of each other every month — so it remains a genuine, unexplained, portfolio-wide trend.
