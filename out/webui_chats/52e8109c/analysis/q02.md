## Question
give me some charts

## Answer
Built a 5-chart dashboard from live queries against `clickathon` (all verified by set-membership join per known_issues.md → D1, not `windowFunnel`, which loses 52% of true conversions on this data):

1. **Main visa funnel** (baseline, H1 2026): 1,000,000 card clicks → 154,413 applications (15.44%) → 20,446 doc uploads (13.24%) → 14,739 pay clicks (72.09%) → 7,054 purchases (47.86%). End-to-end `funnel_conversion` = 7,054/154,413 = **4.57%**.
2. **Group/Family completion rate by group size** (spec 02, 2026-06-08→06-28, 1,200 groups): monotonic decline from **69.47%** (size 2) to **31.11%** (size 6).
3. **Instant Forex attach rate by destination** (spec 05, same window, 2,900 offers shown): best **US 24.58%**, worst **AU 13.78%**, ~11pp spread across 14 destinations.
4. **Abandoned-checkout recovery rate by drop step** (spec 04, 2026-06-08→07-01, 2,300 abandonments): flat 4.45%–4.80% for the first three funnel steps, notably worse at **2.62%** for the earliest drop point (`destination_card_clicked`).
5. **Monthly funnel-conversion trend** (baseline, Jan–Jun 2026, July excluded as a 9-row partial fragment): a real portfolio-wide decline from **4.94%** (Jan) to **3.96%** (Jun), ~20% relative drop despite rising application volume — and per K4, not Schengen-specific (Schengen and other destinations track within ±0.3pp every month), so it remains genuinely unexplained.

Scope/caveats: charts 2–4 come from newly-instrumented spec tables whose `application_id` has **0% overlap** with the main funnel (known_issues.md → D2) — they are analyzed standalone via their own keys (`group_id`, `user_id`), not joined back to `destination_card_clicked`/`application_started`. All five charts' underlying counts were re-queried live on 2026-08-02 and match the wiki's previously-verified figures exactly.
