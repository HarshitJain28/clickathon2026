## Question
AOV uplift: distribution of `addon_value_inr` among attachers.

## Answer
"Attachers" = the 546 users in `forex_purchased` — the event where the forex add-on is actually paid for (the table `forex_purchased.md` itself labels this ratio, 546/2,900 vs. `forex_offer_shown`, as the PM's "attach rate"). Live query against `clickathon.forex_purchased` (all 546 rows, 100% `from_currency = INR`, so no cross-currency mixing per D7):

| Stat | Value (INR) |
|---|---:|
| n (attachers) | 546 |
| min | 4,245 |
| p10 | 10,188.5 |
| p25 | 16,560.75 |
| median (p50) | 31,685 |
| mean | 40,587.77 |
| p75 | 56,488.75 |
| p90 | 85,086 |
| p95 | 108,754.25 |
| max | 130,911 |
| population stddev | 30,415.32 |

The distribution is right-skewed: mean (₹40,588) sits well above the median (₹31,685), driven by a long tail of high-value add-ons up to ₹130,911. This means a straight "mean uplift" figure overstates the typical order — median or a trimmed measure is the safer read for a typical attacher's AOV bump.

For reference, the earlier funnel stage `forex_added_to_cart` (725 users who added the add-on to cart, whether or not they went on to pay) shows a nearly identical shape — min ₹4,135, median ₹31,911, mean ₹39,601.71, max ₹134,453 — so the value distribution doesn't shift meaningfully between "added to cart" and "actually paid."

**Scope/caveats:** sample is the Instant Forex spec window (2026-06-08 06:00 → 2026-06-28 23:12), 546 rows for the attach event, single currency (`from_currency = INR` for 100% of rows in this sample — per known_issues.md D7, do not sum this with `purchase_completed.value` without stating it's a separate revenue line, and re-check the currency split if a later sample introduces non-INR rows). `forex_purchased.application_id` has 0% overlap with `application_started` (D2 verdict) — this add-on flow is standalone and not joinable to the main visa funnel, so this distribution describes the add-on's own value only, not a joined "with-addon vs. without-addon" order total; no `purchase_completed`-level AOV comparison was computed here.
